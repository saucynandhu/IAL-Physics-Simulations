# 🧪 IAL Physics Simulations

A comprehensive collection of interactive physics simulations built for IAL (International A-Level) Physics students. Each simulation visualizes key physics concepts through animations, graphs, and interactive controls, making it easier to understand fundamental laws and behaviors.

---

## 🌟 Key Features

### 🧭 Navigation System
- **Home Button**: Easy navigation back to main page from any simulation
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Sticky Navigation**: Navigation bar stays accessible while scrolling
- **Modern UI**: Gradient backgrounds with smooth hover effects

### 📚 Cross-Reference Learning
- **Suggested Simulations**: Each page recommends 4 related physics simulations
- **Educational Flow**: Logical connections between related physics topics
- **Interactive Cards**: Hover effects and smooth transitions between simulations

---

## 📂 Complete Simulations List

### Mechanics & Motion
- **3D Pendulum**  
  Visualizes pendulum motion in 3D space with angular momentum and oscillatory behavior.

- **Hooke's Law**  
  Demonstrates spring mechanics, elastic limits, and force-extension relationships with educational graphs.

- **Simple Harmonic Motion**  
  Explores oscillatory motion with mass-spring systems and pendulums, including displacement, velocity, and acceleration graphs.

- **Circular Motion**  
  Interactive visualization of centripetal force, circular velocity, and angular momentum with real-time graphs.

- **Projectile Motion**  
  Interactive projectile launcher showing trajectory paths, time of flight, range, and motion under gravity.

### Waves & Optics
- **Standing Waves**  
  Simulates nodes and antinodes in strings, highlighting wave interference and harmonics with interactive controls.

- **Diffraction Patterns**  
  Simulates wave diffraction through slits, showcasing interference patterns and wave propagation.

### Electromagnetism & Modern Physics
- **RC Circuits**  
  Demonstrates capacitor charging and discharging behavior with real-time voltage, current, and charge graphs.

- **Magnetic Fields**  
  Cloud chamber simulation visualizing charged particle motion in magnetic fields with Lorentz force demonstrations.

- **Radioactive Decay**  
  Interactive simulation of exponential decay, half-life concepts, and nuclear physics with multiple isotope options.

- **HR Diagram**  
  Interactive Hertzsprung-Russell diagram for stellar evolution, showing star classification and relationships.

### Fluid Dynamics
- **Stokes' Law**  
  Visualizes drag force on spheres in viscous fluids and terminal velocity behavior.
