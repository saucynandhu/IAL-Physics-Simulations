# 🧪 Physics Simulations

A collection of interactive physics simulations built using HTML, CSS, and JavaScript. Each simulation visualizes a key physics concept, making it easier to understand fundamental laws and behaviors through animations and interactivity.

---

## 📂 Simulations Included

- **3D Pendulum**  
  Visualizes the motion of a pendulum in 3D space. Demonstrates angular momentum and oscillatory behavior.

- **Diffraction Pattern**  
  Simulates wave diffraction through slits, showcasing interference and wave propagation.

- **Hooke's Law**  
  Demonstrates spring motion under Hooke’s Law. Real-time force and displacement visualization.

- **Projectile Motion**  
  Interactive projectile launcher that shows trajectory paths, time of flight, and range.

- **Standing Waves**  
  Simulates nodes and antinodes in a string, highlighting wave interference and harmonics.

- **Stokes’ Law**  
  Visualizes drag force on a sphere in a viscous fluid and terminal velocity behavior.

---

## 🛠️ Technologies Used

- HTML5 for structure
