Standing Wave Theory

Basic Principles

A standing wave is a wave that remains in a constant position. It occurs when two waves of the same frequency and amplitude travel in opposite directions and interfere with each other.

Where:

  • f is the frequency (Hz)
  • n is the harmonic number
  • L is the length of the string (m)
  • T is the tension in the string (N)
  • μ is the mass per unit length (kg/m)

Key Concepts

  • Nodes and Antinodes:
    • Nodes: Points of zero displacement
    • Antinodes: Points of maximum displacement
    • Number of nodes = n + 1
    • Number of antinodes = n
  • Harmonics:
    • Fundamental frequency (n=1)
    • Second harmonic (n=2)
    • Third harmonic (n=3)
    • And so on...
